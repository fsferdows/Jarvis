## 🌟 What is J.A.R.V.I.S.?

**J.A.R.V.I.S.** is a complete, production-grade recreation of Tony Stark's iconic artificial intelligence system. Unlike typical voice wrappers or chatbot UIs, J.A.R.V.I.S. is a **fully integrated autonomous OS companion** featuring real-time audio cloning, zero-screenshot browser vision, reverse-engineering capabilities, and full system actuation on macOS.

Say **"Hey Jarvis"**, and he wakes, listens, reasons, and executes actions across your operating system in real-time.

## 🚀 Key Superpowers

### 🎙️ 1. OmniVoice Zero-Shot Neural Voice Cloning (Sub-500ms)
- **Acoustic Fidelity**: Cloned directly from Paul Bettany's original J.A.R.V.I.S. voice with crisp British butler cadence (`male, british accent, low pitch`).
- **Hardware-Accelerated**: Runs locally on Apple Silicon Metal Performance Shaders (`mps`) using `k2-fsa/OmniVoice`.
- **Instant Response Cache**: 51 pre-warmed conversational acknowledgments deliver audio playback in **~405 ms**.
- **100% Private**: Your voice never leaves your machine.

### 🧠 2. OmniRoute Autonomous Model Router (`http://127.0.0.1:20128`)
- **Smart Model Routing**: Seamlessly arbitrates queries between fast local inference (`ollama-local/qwen2.5`) and over 350 cloud models.
- **Failover & Resilience**: Automatic provider circuit breakers, token compression, and intelligence scoring.
- **Zero Configuration**: Authenticated locally via dedicated autonomous key pairs.

### 🔬 3. REA (Reverse Engineer Anything) Engine
- **153 CLI Commands & 207 Analysis Tools**: Built-in developer toolkit to decompile, analyze, and inspect binaries.
- **Target Coverage**: Native Mach-O/ELF binaries, Electron unpacked ASARs, Android APKs, Web single-page app bundles, and firmware.
- **Direct Voice Directives**: Simply say *"Jarvis, reverse engineer this binary and inspect its functions"* or *"Decompile this Electron application"*.

### 🦞 4. OpenClaw Multi-Agent Orchestration
- **Autonomous Agent Turns**: Delegates multi-step objectives to OpenClaw (`/opt/homebrew/bin/openclaw`).
- **Channel Dispatch**: Natively dispatches messages and files through WhatsApp Web, Telegram, and automated channels.
- **ClawHub Skills**: Discovers, verifies, and installs skills on demand.

### 👁️ 5. Agent Reach (Zero-Screenshot Browser Vision)
- **High-Speed DOM Inspection**: Reads open Chrome tabs, extracts live text, evaluates JavaScript, and tracks Meta/Google Ads metrics without burning tokens on expensive vision screenshots.
- **Live Tab Navigation**: Switch, query, and interact with browser workflows hands-free.

### 🦾 6. Iron Man Protocol (macOS Actuation)
- **Application Control**: Open or cleanly close applications (Google Chrome, WhatsApp, Spotify, Terminal, Calendar, Notes, System Settings).
- **Media & Hardware**: Adjust system volume, toggle mute, control Spotify/Apple Music tracks, query battery status, or lock screen.
- **Calendar & Notes**: Book events with date/time parsing and append formatted entries to Apple Notes.
- **Terminal Execution**: Safely run shell commands with butler confirmation reports.

### 🔮 7. Holographic 3D Arc-Reactor Interface
- **Three.js & Custom GLSL**: Shaders render an authentic glowing holographic HUD that pulses and ripples in direct sync with audio frequency bands.
- **Interactive Controls**: Touch, orbit, and hand-tracking support via MediaPipe.

## ⚡ Quickstart Guide

### Prerequisites
- **macOS** (Apple Silicon M1/M2/M3/M4 recommended for MPS acceleration)
- **Node.js** `>= 20.0.0`
- **Python** `>= 3.10`
- **Google Chrome** (for WebGL HUD and Agent Reach)

### 1. Clone the Repository
```bash
git clone https://github.com/fsferdows/Jarvis.git
cd Jarvis
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Launch J.A.R.V.I.S.
```bash
# Starts both the face (React Vite HUD) and brain (WebSocket Bridge & Actions)
node scripts/start.mjs --writes
```

Open **`http://localhost:5173`** in Google Chrome, click **INITIALISE**, and say:
> *"Hey Jarvis, status report."*

## 🛠️ Architecture & Tech Stack

- **Frontend HUD**: React 19, Vite, Three.js, WebAudio API, GLSL Shaders, Tailwind CSS.
- **Bridge Engine**: Node.js ESM WebSocket Gateway (`ws://localhost:8787`), Model Context Protocol (MCP) server.
- **Voice Engine**: `k2-fsa/OmniVoice`, PyTorch MPS (Metal Performance Shaders), SoundFile.
- **Model Router**: OmniRoute smart proxy (`http://127.0.0.1:20128`), Ollama (`qwen2.5:3b`, `qwen2.5-coder`).
- **Autonomous Agent**: OpenClaw CLI, ClawHub registry.
- **Reverse Engineering**: `rea-agents` v6.7.0 CLI & decompiler plugins.
- **Browser Automation**: Agent Reach CDP (Chrome DevTools Protocol) bridge.
